# Module 1 - AI-Based Real-Time Vernacular Translation

## Aim
Translate English educational content into Tamil for mother-tongue-based primary education.

## Input
English educational sentence or paragraph.

## Output
Tamil translation.

## Flow
English text -> Flask API -> translation layer -> Tamil result -> React UI

## Initial demo
The UI and Flask API are runnable locally. The translation layer is intentionally isolated so the actual IndicTrans2 model can be integrated in the next implementation stage.
